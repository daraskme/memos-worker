# Screenshot provenance

These screenshots were captured from a separate loopback-only development server at port 8790, using a newly initialized local D1 database and `scripts/seed-demo.mjs`.

- `cards.png`: nine fictional notes in the card view.
- `board.png`: the same fictional notes grouped into category columns.

No production database, real memos, user attachments, authentication tokens, or account details were used. The avatar belongs to the local preview account. The demo can be reproduced using the README's local setup and `npm run demo`.
